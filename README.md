# Shaadi Market Index 💍

> **A satirical, AI-powered tool that exposes the absurdity of treating people as commodities in arranged-marriage negotiations.**

---

## What is this?

**Shaadi Market Index** is a command-line satire project powered by Google Gemini. It collects a detailed personal profile — education, income, family background, lifestyle, personality — and uses an AI model to generate a fictional "market valuation", along with compatibility, prestige, and tradition scores.

The output is intentionally ridiculous. That's the point.

The project mirrors the real-world logic used in certain arranged-marriage negotiations back at itself, making visible how dehumanizing it is to reduce a person to a financial estimate based on caste, profession, or height.

---

## Features

- **Comprehensive profile collection** across 8 categories: basic details, assets, career, family, lifestyle, personality, marriage expectations, and traditional factors
- **Gemini-powered analysis** via `google-generativeai` — the AI plays the role of the absurd appraiser
- **Structured JSON output** parsed into typed Python dataclasses
- **INR-formatted monetary output** with Indian number system formatting (lakhs/crores style)
- **Reality Check section** — every report ends with a grounded counter-narrative

## Setup

### 1. Clone / extract the project

```bash
cd shaadi-market-index
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure your API key

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_google_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash   # optional, this is the default
```

You can get a free Gemini API key from [Google AI Studio](https://aistudio.google.com/).

## Disclaimer

This project is **satire and social commentary**. The "valuations" it produces are fictional and generated by an AI playing a deliberately absurd role. They are not real assessments of any person's worth.

Treating people — of any gender — as having a monetary value in the context of marriage is harmful, illegal under Indian law, and the exact mindset this tool is designed to critique.
